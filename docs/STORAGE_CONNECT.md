# Подключение облаков с любого устройства

Облако подключается из чата одной ссылкой, без терминала и проброса портов.

1. В чате: «подключи Google Drive» → `storage_connect provider=drive`.
2. MCPshka отвечает ссылкой `https://<публичный адрес MCPshka>/storage/connect/<код>` (одноразовая, 10 минут).
3. Открыть её в любом браузере (телефон, планшет, компьютер), войти в облако и разрешить доступ.
4. Страница «Готово» — токен уже в root-only vault; проверить `storage_auth_status provider=drive`.

MCPshka получает код по адресу `/storage/callback`, обменивает его на токен с PKCE и передаёт брокеру (`auth_accept`). Токен не проходит через чат и не показывается. В конфиг rclone записываются и `client_id`/`client_secret` приложения, иначе rclone не сможет обновлять токен.

## Страница подключения (0.12.0)

Ссылка выдаётся всегда, даже когда у облака ещё нет приложения OAuth. Страница:

- **приложение есть** — сразу ведёт на вход в облако;
- **приложения нет** — показывает шаги со ссылками на консоль облака, точный адрес возврата `https://<публичный адрес MCPshka>/storage/callback` и форму для Client ID и Client secret. Ключи сохраняются в `/var/lib/mcpshka/secrets/storage-oauth.json` (0600) и в чат не попадают. `storage_oauth_app_set` делает то же из чата и оставлен для совместимости;
- **Яндекс.Диск, Dropbox** — ещё и «быстро, без настройки»: вход через приложение rclone. В конце браузер открывает адрес `127.0.0.1:53682`, которого на телефоне нет, — его нужно скопировать из адресной строки и вставить на странице.

Особенности облаков:

- **Google Drive** — только своё приложение: общий ключ rclone отключают в 2026 году, и он упирается в лимиты. В Google Auth Platform приложение нужно опубликовать («Publish app»), иначе доступ пропадёт через 7 дней. Запрашивается весь Диск; при входе Google покажет «приложение не проверено» — это собственное приложение владельца, «Дополнительные настройки» → «Перейти».
- **Яндекс.Диск** — приложение «Веб-сервисы», доступы Яндекс.Диск REST API (чтение, запись, информация).
- **Dropbox** — Scoped access, Full Dropbox, разрешения files.content.* и files.metadata.*.

Проверка: `storage_auth_status provider=<облако>` читает облако вживую — `connected` либо `credential_rejected` с причиной.

iCloud Drive так не подключается: у Apple нет OAuth для пользовательского iCloud Drive.

Публичный адрес пропускает только `/storage/connect/*` и `/storage/callback` (Caddy, `/etc/caddy/mcpshka-faceid.caddy`).
