# MCPshka 0.19.2

Выпуск 25.11: быстрое вливание, безопасность публикации открытого ядра, новый README и первые вырезки монолитов.

## Быстрое вливание (S5.FAST)
- **Гейт вливания проверяет только задетое.** Изменённые пакеты, их обратные зависимости, архитектурные проверки и орфография документов. Полный набор — при изменении go.mod/go.sum, CI, packaging, заметок выпуска, версии, distributedci или ci-shard; любая ошибка выбора тоже даёт полный набор. Список пакетов запечатан в окружении запуска (профиль module:affected).
- **Выпуск всегда полный:** квитанция выпуска отвергает частичное доказательство (TEST_EVIDENCE_PARTIAL).
- **Архитектурные проверки идут первыми:** превышение лимита строк монолита падает за секунды, а не через 40 минут полного набора (25.11 вливание 0194 потеряло 38 минут на +12 строк executor).
- **Куски распределённого CI — по числу площадок (4).** H96 может прогнать любой кусок сам; тест: все четыре площадки недоступны — H96 делает всё, по одному куску.
- GitVerse: статус прогонов читается с первой страницы списка (пагинация).

## Открытое ядро
- **Токен больше не виден в ps:** заголовок авторизации идёт через GIT_CONFIG_* в окружении git, а не в argv. У каждой git-команды предел 3 минуты и отбой при низкой скорости.
- **Публикация не обрывается таймаутом клиента:** opencore_publish работает отвязанно от запроса (25.11 SourceCraft отставал, потому что клиент закрывал запрос через 60 с).
- **README по образцу топовых Go-проектов:** README.md (английский) и README.ru.md (русский) одной структуры — возможности, быстрый старт, установка, подключение клиента, настройка, устройство, безопасность, зеркала, благодарности. История выпусков осталась в CHANGELOG и docs/releases.
- install.sh работает на чистой машине: версию сообщает сам бинарь, без Python-помощника H96.
- CI SourceCraft: Ubuntu 22.04 из зеркала Яндекса, Go с proxy.golang.org.
