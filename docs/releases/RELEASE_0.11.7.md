# MCPshka 0.11.7 — исправление приёмки 0.11.6

Найдено живой проверкой 0.11.6 на ROADMAP Lane: файл когда-то был в Git, потом вышел из индекса. `roadmap_next` считал коммиты от того давнего коммита (434 вместо 90), а `roadmap_close` попытался бы закоммитить неотслеживаемый файл.

- Отслеживаемость ROADMAP определяется по индексу (`git ls-files`), а не по истории. Неотслеживаемый ROADMAP (Lane, MCPshka) считается от времени изменения файла и при закрытии пункта только правится, без коммита.
- Тест `TestCommitsSinceTreatsFormerlyTrackedFileAsUntracked`.

Проверка после установки: `roadmap_next path=/root/repos/lane` — в предупреждении число коммитов после 11.11 17:16 (около 90), не 434.
