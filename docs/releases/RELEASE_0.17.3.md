# MCPshka 0.17.3

- Диагностика таймаута чтения Unix-сокета брокера различает недоступность сокета, задержку и ошибку обработчика; повтор ограничен и допускается только до отправки запроса. MCP-256.
- Штатный `abandon` восстанавливает привязки заброшенного вложенного worktree без admission. MCP-257.
- Состояние SQLite сообщает о заполнении ёмкости, а явные отказы аудита, которые заведомо не начались, освобождаются. MCP-258.
- Владелец может применить релиз из консоли с аудитом по защищённому свидетельству. MCP-259.
- Sealed-стадия полного Go-теста использует управляемый дедлайн задания (`go test -timeout=0`) вместо внутреннего лимита пакета Go; набор пакетов и проверки не сокращены. MCP-262.
