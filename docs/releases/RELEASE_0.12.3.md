# MCPshka 0.12.3

## Подключение ИИ-чата: «Authentication succeeded, action discovery failed»

После переезда Face ID и страниц MCPshka на родной адрес приставки (`pristavka…ts.net`) новый плагин ChatGPT проходил вход по Face ID, но не получал список инструментов. В журнале прокси: `POST /mcp` от `openai-mcp` — 403, тело `Forbidden: invalid Host header "pristavka…"`.

Отвечала не MCPshka, а библиотека MCP (go-sdk): её защита от подмены DNS отклоняет любой запрос с нелокальным именем в `Host`, пришедший на локальный сокет. Портал всегда слушает `127.0.0.1` за HTTPS-прокси, а имя узла MCPshka проверяет сама — по настроенному адресу входа — ещё до проверки токена.

Теперь после этой проверки запрос передаётся обработчику MCP с локальным `Host`. Чужое имя узла по-прежнему получает отказ от MCPshka.
