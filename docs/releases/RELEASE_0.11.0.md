# MCPshka 0.11.0 — единая память

- **Память** (`internal/memory`, `memory_write`, `memory_recall`): один приватный memory.db рядом со state.db. Поиск BM25 FTS5 по словам (unicode61, префиксы лёгкой основы) и по формам (trigram) на любом языке; языки без пробелов (китайский, японский, корейский, тайский…) — парами символов. Слияние RRF, затем сигналы: вид записи, канон, проект, свежесть; без модели и сети на чтение. Двувременные факты: новая запись с тем же видом/проектом/заголовком закрывает старую (valid_to, superseded_by), `as_of` отвечает «что было правдой тогда». Напоминания: `memory_write kind=reminder remind_at`, `memory_recall due=true`.
- Знания: уроки из принятых карточек (149 из 293 записей) теперь в поиске; вся видимая база знаний зеркалится в память при каждой переиндексации.
- MCP-167: lease удалённого worktree читается по точному корню и снимается stale_release; mission_status его не считает неполнотой.
- integration_ship: отказ forge_ci из-за удержанного lease — стадия `LEASE_HELD` вместо вечного CI_OBSERVING и ухода на GitHub.
- self-heal: работающий контейнер без сетевого endpoint (torrserver 10.11) перезапускается; контейнер без healthcheck считается восстановленным, когда работает и подключён.
- Каталог инструментов 287 (+memory_write, memory_recall).
