# MCPshka 0.9.7

## Раннеры: подключение одной строкой (владелец 09.11: «удобная настройка IDE, а не танцы с бубном и копипаста»)
- `GET /runner/setup` — установщик: `curl -fsSL <origin>/runner/setup | sh -s <токен>`. Ставит агента, автозапуск в `~/.bashrc`, убирает старые следы, ключ хранит в рабочей папке IDE (`/workspaces`, `~/workspace`), которую та не стирает (на GigaIDE пропал `~/.mcpshka-runner.json`). Повтор без токена — `… | sh`.
- Страница «Раннеры»: одна строка с кнопкой «Скопировать», вторая — для повтора, если IDE сбросила настройки.
- `agent.py` v2: `--conf` (путь ключа); перенос старого ключа из `~` сам.

## Балансировка нагрузки

- Гайд `runners`: порядок маршрутов — живой раннер → CI GitVerse → `project_test` на H96 последним.
