# MCPshka 0.11.4 — исправление приёмки 0.11.3

Приёмка 0.11.3 на проде (10.11): `mcpshka memory-vectors` прошёл (120 тыс. слов), экзамен памяти — R@1 0,908, R@3 0,985 (цели 0,85 / 0,95), но `mcpshka memory-questions` дважды упал «memory sqlite: signal: killed».

**Причина.** Запись вопросов (`SetQuestions`: `memory_write questions`, `question_sets`, `memory-questions`) после вставки в `mem_q` пересобирала словесные индексы и векторы **всей** памяти одним вызовом sqlite, а у каждого вызова бюджет 8 с. На копии памяти в лаборатории это успевало, на нагруженном проде (≈360 записей, работающий сервер) — нет. Значит, и обычный `memory_write` с вопросами в проде упал бы так же.

**Исправление.** Вопросы переиндексируют только свои записи (по source своих записей и id копий знаний): удаляются и заново пишутся их строки индексов и вектор. Полная пересборка (`Reindex` после `memory-vectors`) получает отдельный бюджет 2 минуты. Тест: после вопросов к одной записи другая по-прежнему находится по своим словам.

Проверка после установки: `mcpshka memory-questions`, повторный импорт памяти Claude, `mcpshka memory-eval`.
