# MCPshka 0.19.3

Выпуск 26.11: автономность по разбору сегодняшних чатов ChatGPT (владелец перестаёт писать «продолжай»), CI открытого ядра в публичных репозиториях, метрики автономности.

## Автономность
- **Агент не погибает от одного пропущенного пульса lease:** терпит до 5 подряд транзиентных промахов, останавливается сразу только на отказе без эффекта (MCP-288).
- **Освобождение lease ждёт собственный тест агента:** PROJECT_BUSY от своей задачи в очереди повторяется до 30 мин, задача больше не уходит в UNKNOWN при исчерпании лимита (MCP-289).
- **Итог любой фоновой работы:** пакет runoutcome — состояния idle / no_effect / partial с блокером и следующим шагом; ночной разбор, синхронизация сессий и запланированные задачи записывают реальный эффект, пустой проход больше не выглядит успехом.
- **Единая структура ошибки:** конверт failure (класс, блокер, next_safe_action) у всех инструментов; готовность бэкенда — с доказательством, а не флагом.
- **phase_gate** прямо говорит, что выборочный project_test не запечатывает фазу, и называет нужную команду.
- **Правило 18 для ИИ-клиентов:** ложные стоп-сигналы (backend_healthy=false, BUSY/OWNER_BUSY, ошибка схемы, CAPABILITY_MISSING на угаданном имени, выборочный PASS) — не повод заканчивать ход.
- **Метрики автономности:** autonomy_metrics / autonomy_baseline_save — подталкивания владельца («продолжай», «почему остановился»), вызовы, агенты, нагрузка; строка в ночном разборе.

## Инструменты
- **code_run:** работает await, два запуска одновременно с ожиданием до 8 с вместо BUSY, до 50 вызовов; принятые ответы LLM не теряются при BUSY.
- **tool_resolve** по угаданному имени (git_push, issue_search) находит настоящий инструмент; части имени ищутся в имени и псевдонимах, не в описании.
- **Память:** выборка только по тегу; у записей с общим source свои вопросы; разбор архивов чатов Claude Code и Codex (memory_archive) вручную и по расписанию.
- **issue_create** прикладывает снимок: версия, здоровье хоста, шлюз LLM, последние ошибки инструментов, контекст проекта.
- **Помощники только по просьбе:** FreeLLM и GigaChat не подменяют основной мозг; отказ шлюза перечисляет другие настроенные модели.

## CI и площадки
- **Распределённый CI в публичных репозиториях открытого ядра** (бесплатные минуты): куски уходят на ветки ci/<commit>/shard-N только как выгрузка ядра с пройденным аудитом секретов; аудит повторяется перед push, сырое дерево не публикуется никогда. Старые ветки ci/** убирает уборка (MCP-291).
- **GitFlic** — пятая цель открытого ядра (lda6994/mcpshka); приватные снимки — lda6994/mcpshka-ci. Общих агентов у GitFlic нет: только зеркало.
- Пункты roadmap вне фаз P сверяются с CI; ship продолжает свой элемент по коммиту; integration_import_github_main принимает внешний main GitHub только fast-forward с Face ID.
