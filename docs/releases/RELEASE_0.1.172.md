# MCPshka 0.1.172 — внешние ИИ не теряют инструменты, сайты без API, проекты под Face ID

## ChatGPT и другие клиенты со старым снимком каталога
- **Любой инструмент через `exec_start`**: `command=mcpshka args=["tool-invoke","<имя>","<JSON>"]` (а также `["guide","rules"]`, `["resolve","<цель>"]`) вызывает инструмент со всеми его защитами. У ChatGPT замороженный `tools/list`, а `exec_start` в нём есть всегда.
- **`client_catalog_status`**: MCPshka записывает последний полный `tools/list` каждого клиента и показывает, каких инструментов ему не хватает. Так видно, помогло ли обновление коннектора. `capabilities_bootstrap` говорит устаревшему клиенту прямо: «тебе не хватает N инструментов, вызывай так».
- **Отказы `exec_start` подсказывают путь к типизированному инструменту.**
- **`tool_resolve` понимает русский**: нормализация слов, совпадение по основе, веса (слово инструмента > слово категории), стоп-слова, русские синонимы у ходовых инструментов, у каждой категории справки свои русские слова. Бенчмарк: 38 из 38 фраз владельца, 10 из них не скопированы из синонимов. Раньше у 169 инструментов не было русских слов.

## Новое
- **`project_repo_preview` / `project_repo_adopt`** (Face ID): создать `/root/repos/<имя>`, перенести туда `/root/<имя>` или отдать службе проект с файлами root. План закрепляется SHA, применение заново обходит дерево и отказывает при любом расхождении. chown идёт через дескрипторы с O_NOFOLLOW, перенос — `RENAME_NOREPLACE`. Скрипты chown владельцу больше не нужны.
- **`browser_run` / `browser_screenshot`**: headless Chromium для сайтов без API (запуск GigaIDE, секреты GitVerse, настройки MosHub). CDP через `--remote-debugging-pipe`: без порта отладки и без новых зависимостей. Ограниченное задание (180 с, 1 ГиБ), песочница Chromium, прогон привязан к одному сайту, профиль сессии на сайт. click/type и импорт cookies — только под Face ID.
- **Офлайн-образ CI для MosHub собирает GitVerse CI** (`moshub-ci-image.yml`), MosHub берёт его из `MOSHUB_CI_IMAGE`.
- **Метка доказательства `ci:gitverse`** вместо `ci:github` для прогонов GitVerse.
- **host_triage: выключенные `fs.protected_*`** (на этом ядре все четыре = 0); скрипт владельца `/root/mcpshka-run/harden-links.sh`.
