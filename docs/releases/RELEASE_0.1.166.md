# MCPshka 0.1.166 — окружения проектов без ручной настройки

## Новое
- **MCPshka сама готовит зависимости проекта.** По файлам зависимостей коммита (`requirements*.txt` → venv, `package.json` + `package-lock.json` → `npm ci`) root вычисляет ключ окружения; worker один раз собирает его в отдельной песочнице с сетью (только DNS и сертификаты, пользователь песочницы, 15 мин) в кэш исполнителя и атомарно публикует. Тест проекта видит окружение только на чтение в `/env` (`PATH`, `VIRTUAL_ENV`) и остаётся без сети. Ошибка сборки — результат запуска с выводом. Никаких списков на конкретный проект.
- **MosHub** (ветка Codex): неизменяемые снимки по проверенному HTTPS, CI-конфиг, наблюдатель статуса pipeline (раннеру MosHub пока недоступен источник SQLite — разбор продолжается).
