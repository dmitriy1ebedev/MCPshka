# MCPshka 0.1.185 — подключение облаков с любого устройства

Включает 0.1.184 (облачные хранилища, зашифрованный бэкап, база знаний с ревизиями), которая не устанавливалась отдельно.

- `storage_connect` — одноразовая ссылка (10 минут) на публичном HTTPS-адресе MCPshka: открыть в любом браузере (телефон, планшет, компьютер), войти в Google Drive / Яндекс.Диск / Dropbox, разрешить — токен сразу в root-only vault, ничего не копируется. PKCE, код меняется на токен на стороне MCPshka. Нужен один раз зарегистрированный OAuth-app облака (`storage_oauth_app_set`); `storage_connect` подсказывает шаги. Описание — docs/STORAGE_CONNECT.md.
- Хранилище токенов записывает client_id/client_secret приложения в конфиг rclone — без них токен своего приложения не обновлялся бы.
- BUG-20261024-103: `forge_ci` падал на старте (pthread_create) — лимит процессов поднят с 16 до 64.
