# MCPshka 0.9.0 — объединённый выпуск: Gateway, durable-миссии, честные отказы

Дата подготовки: 2026-11-08.
Статус: CANDIDATE до `project_verify expected_version=0.9.0`.
База: защищённый main cc0095f1e67ede0516836ff3daccf2655764302f (0.8.1, откат — 0.8.1).

Выпуск сводит в один main всю работу, накопленную на приставке после 0.8.1:
23 коммита Codex (ветка forge/914c606809742314, 06–07.11) и чекпоинт DISRUPT.

## Включено

- **Stable MCP Gateway (S5/P25):** шесть стабильных операций поверх существующих
  границ инструментов — малый неизменный внешний интерфейс для ChatGPT и других
  клиентов; динамика через `tool_resolve`/`tool_invoke`; диагностика отказанных
  инструментов. Совместимость шлюза и сессий сохраняется.
- **Миссии и Roadmap Run (P7/P29):** durable-контроль миссий на входе workflow,
  атомарный приём закреплённых workflow, изоляция именованных workflow,
  продолжение закреплённых одобрений после Face ID, явное согласие исполнителя,
  ограждение неподдерживаемых команд миссии при откате на 0.8.1.
- **Агенты:** согласие владельца на набор агентов в корне и при каждом
  возобновлении; задачи владеют своим lease; неизвестные попытки сохраняются до
  сверки перед возобновлением по квоте; ограниченный вывод; честная сверка
  перегрузки провайдера.
- **Lease:** атомарная запись учётных данных держателя, ограждение idle-release.
- **Честные отказы MCP:** проверенные факты отказа сохраняются через пробы,
  цепочки, durable-повторы, gateway и HTTP-маршруты; no-effect preflight честный;
  сверка исходного эффекта не стирает pending-квитанции.
- **Реестр инструментов:** согласованная публикация динамических реестров без гонок.
- **Приёмка в прод:** привязка к подписанному парному доказательству источника.
- **Salvage:** сверка закреплённого содержимого, сохранение неполного WIP.
- **Discovery:** отказ при отсутствии регистрации хоста, причины планирования сохраняются.
- **CI:** нативные контракты выпуска и root-политики в snapshot-наборе, закреплённые
  нативные зависимости тестов в изолированном окружении.
- **Docs:** ADR DISRUPT — распределение идей по фазам roadmap.
- **Controller + broker:** согласованная пара 0.9.0.
