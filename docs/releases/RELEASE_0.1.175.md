# MCPshka 0.1.175 — коннектор Claude за Face ID, наблюдаемость блокировок, починка выпуска

## Коннектор claude.ai (выключен, пока не задан MCPSHKA_OAUTH_ISSUER)
- OAuth 2.1 на публичном портале Face ID: регистрация клиента только для колбэков claude.ai/claude.com, PKCE S256, каждое подключение ждёт Face ID владельца на ровно этот запрос (новая цель passkey `mcp_connector`, одноразово, 10 мин), коды одноразовые на 5 мин, токен доступа 24 ч и обновляемый 30 дней, в базе только SHA-256. Токен действует от учётки `MCPSHKA_OAUTH_IDENTITY` — её отзыв отключает и коннектор. Без настройки `/mcp` на портале отсутствует.

## Здоровье (P8, Codex)
- `health_snapshot`: пробы брокера (версия совпадает с контроллером), исполнителя (зависшие permit и юниты), провайдеров Codex/Claude (авторизация и квота — отдельные сигналы, неизвестное не зелёное); у каждого не-ok источника — свежесть и готовый `next_safe_action`. Деградация LANE/индекса не делает туннель и Docker «offline».
- Контейнер в состоянии unhealthy так и называется (zigbee2mqtt показывался «running», когда лежал); поисковый индекс устаревает только по ревизии, а не по возрасту.
