Workflow живёт в снимке коммита, поэтому сам 0.16.3 уже проверяется исправленным распределённым CI.

## FreeLLM-конвейер

Первый ночной прогон (7644c5b) дал 0/6: контролёр видел только auto и одно
угаданное имя, HTTP-ошибки не содержали объяснения, таймаут code_run был 60 с.
Теперь `llm.models()` читает каталог FreeLLMAPI; неизвестные модели проверяются
коротким запросом, результаты кешируются на 5 минут. Отказ/503/таймаут задания
переключают на следующую модель без повторов в пределах общего бюджета.
Ответ `llm.ask` содержит text, фактическую model и число/типы редакций.
`llm.compare` собирает N разных ответов (по умолчанию 3); дубликат модели
не считается отдельным голосом, неполный набор явно отмечается complete=false.

Секретные фрагменты заменяются на [REDACTED:тип], остальной текст можно
отправить. Удаляются и тела private key, и хвост известного секретного префикса.
Исправлены ложные known_secret от env-значений и путей в полях key_file/token_path;
длинные имена тестов/ссылки на функции больше не блокируют весь запрос.
Строгий фильтр для HTTP/PDF не ослаблен. Тела ошибок провайдера очищены и ограничены.

Таймаут задания по умолчанию 90 с, общий бюджет 180 с; конфиг и параметры вызова
позволяют их менять. `code_run timeout_seconds` допускает до 600 с; для длинных
LLM-вызовов его нужно задать явно и согласовать с таймаутом клиента.

`llm.scope` исключает карточки другого проекта или с изменяемыми путями вне
текущего репозитория. Отдельного ночного инструмента нет; минимальный порядок
отбора, сравнения ответов и проверки diff описан в `docs/freellm/CONVEYOR.md`.

Проверки: httptest-провайдер (503, таймаут, успех следующей модели, кеш и
неполный кворум), канарейки редакции, границы карточек, JS-контракт и бюджет,
снимок каталога, archlint. Живая проверка FreeLLMAPI после установки остаётся
этапом приёмки выпуска; этот коммит не публикует и не устанавливает выпуск.
