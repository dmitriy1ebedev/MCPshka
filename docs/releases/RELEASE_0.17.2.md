# MCPshka 0.17.2

- Диагностика хоста сообщает о рискованных настройках журнала корневой ext4. MCP-180.
- При явном отказе из-за истечения Face ID во время агентской задачи MCPshka сохраняет неопределённый результат для сверки перед продолжением. MCP-226.
- Держатель может освободить lease удалённого worktree после проверок простоя, деплоя и токена. MCP-254.
- Инспектор Samba читает фиксированный конфиг через брокер и возвращает ограниченную сводку по распознанным шарам. MCP-250.
- FreeLLM возвращает очередь fixes_review в поле `fixes`. Для просмотра очереди путь worktree необязателен. MCP-255.
- `project_commit` принимает полную карту SHA-256 перед коммитом, а Git обрабатывает имена файлов буквально. MCP-217.
- `list_searches` перечисляет активные поисковые сессии вызывающего. MCP-246.
- Диагностика показывает параметры зарегистрированного SSH-узла, проверяет закреплённую Tailscale-идентичность и показывает исходящий маршрут управления. MCP-080, MCP-081, MCP-094.
- Sealed-тесты и зарегистрированные workflows используют точный SHA вложенного worktree и читают Git-объекты из проверенного канонического репозитория. MCP-232.
- Диагностика webOS показывает состояние локальной пары и отпечаток проверенного публичного ключа LG. MCP-196.
- Зарегистрированный Node.js браузерный тест может перейти в sealed workflow под управляемым lease. MCP-216.
- Отчёт установки webOS сохраняет подтверждённую версию приложения, даже если последующая настройка запуска завершилась ошибкой. MCP-194.
