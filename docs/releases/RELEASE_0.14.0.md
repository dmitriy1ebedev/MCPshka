# MCPshka 0.14.0 — 2026-11-17

Курс на упрощение (решение владельца 15.11.2026): меньше инструментов на виду, надёжнее выпуск.

## Главное
- **Каталог ядра.** tools/list — 53 инструмента вместо ~250. Всё прочее — через `tool_invoke` (схема — `tool_resolve`). Ничего не удалено.
- **Выпуск не оставляет MCPshka выключенной.** После 0.13.5 (25 мин без служб) откат поднимает службы при любом сбое, а статус честно показывает HOLD с причиной.
- **Защита дома вернётся.** Установка 0.14.0 снова включает home-priority (выключена откатом 0.13.5, флаг /etc/mcpshka/home-priority-off).
- **Агенты переживают сетевой сбой** (MCP-223), уборка executor больше не копит сироты (MCP-210), сторож не шумит карточками exec_facade.

## Карточки
Fixes MCP-191, MCP-192, MCP-205, MCP-207, MCP-208, MCP-210, MCP-219, MCP-222, MCP-223. Refs MCP-044.
