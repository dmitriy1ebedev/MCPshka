# MCPshka 0.17.0

- `control_plane_https_probe` проверяет DNS и HTTPS двух фиксированных эндпойнтов Tailscale с H96. При выборе IP из текущего ответа DNS сохраняет проверку сертификата исходного имени. Refs MCP-246.
- `host_config_inspect` возвращает структурированную сводку конфигурации Caddy для Face ID и OAuth: привязки, разрешённые маршруты и состояние импорта. Вывод ограничен фиксированными полями и значениями. Refs MCP-247, MCP-248, MCP-249.
- Простые вызовы `ls`, `grep` и `jq` получают маршрут к штатным инструментам. `git add` направляет к атомарному `project_commit`. Fixes MCP-227, MCP-242, MCP-244, MCP-245.
- Портал Face ID сверяет состояние после потерянного ответа. Пакет Caddy включает LAN-сайт Face ID и OAuth. Refs MCP-225, MCP-243.
- FreeLLM проверяет область проекта и допустимые файлы при составлении плана. Refs MCP-231, MCP-239.
- Homeguard отклоняет неполные и противоречивые снимки памяти и swap из procfs. Refs MCP-159.
- Проверки проекта поддерживают проверенные вложенные Git worktree. Диагностика GitVerse классифицирует HTTP 403 с редакцией данных. Refs MCP-206, MCP-232.
