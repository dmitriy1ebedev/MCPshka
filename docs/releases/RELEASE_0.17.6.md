# MCPshka 0.17.6

- **Реестр раннеров больше не отбирается у службы.** Таймер `router-motd-refresh` и стартовые хуки от root читают статус раннеров, а чтение заодно пересохраняет `runners.json`. Файл после этого принадлежал root, MCPshka не могла его прочитать: страница «Раннеры» показывала «permission denied», а каждому раннеру отвечали «runner key refused». Теперь файл и блокировка сохраняются с владельцем каталога (23.11, GigaIDE-раннер r-c33a088297cc).
- «Вход на сайт» убран из меню. Трансляция браузера H96 на телефон оказалась непригодной (медленно, вход через GigaID/Sber ID не проходит). Страница по правилу копилки осталась по прямому адресу.
- GigaIDE: адрес пространства и остаток vCPU-часов заданы в окружении службы. Раннер пространства зарегистрирован заново.
