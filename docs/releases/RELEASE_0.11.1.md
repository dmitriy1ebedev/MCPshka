# MCPshka 0.11.1

Продолжение единой памяти и тишина в покое.

- **MCP-164 — меньше процессов в покое.** Брокер кэширует MainPID службы (по времени старта процесса), держит один sqlite3 на root-базу исполнителя; HEAD/ref git читаются по сигнатуре файлов без запуска git. Цель — меньше 30 запусков в минуту.
- **Напоминания доходят.** `mcpshka memory-brief` — одна строка: число записей и сработавшие напоминания. Показывается в MOTD (в строке MCPshka) и в SessionStart-хуке. Напоминание закрывается `memory_write reminded=true` или кнопкой «Сделано».
- **Импорт памяти Claude.** `mcpshka memory-import DIR [PROJECT]` переносит файлы памяти Claude Code (тип → вид записи; длинные журналы режутся по разделам и абзацам без потерь) и выдаёт отчёт покрытия R@3. Исходник не удаляется.
- **Страница «Память»** (/connections/memory, вход Face ID): поиск на любом языке, запись, напоминания, загрузка файлов с iPhone кусками по 9 КБ с повтором. .md/.txt сразу идут в память, выгрузки чатов ждут разбора в memory-inbox.
- **MCP-161 — `project_worktree`.** create/remove/list рабочих веток без bash: ветка создаётся только вместе с каталогом в /root/repos/wt от служебного пользователя, грязный worktree не удаляется, ветка остаётся.
- HTML страниц вынесен в пакет `webpages` (go:embed), mcpserver стал меньше.
