# MCPshka 0.9.4 — модули вместо монолита, узлы, работа без ручных перезапусков

Дата подготовки: 2026-11-08.
Статус: CANDIDATE до `project_verify expected_version=0.9.4`.
База: 0.9.3.

## Включено

- **Код по модулям** (задача владельца 08.11 «раздутое — в чёткие модули»):
  - `internal/ownerweb` — веб-морда владельца («Подключения», «мозги»,
    OAuth-коннектор, портал Face ID, вход в облака) вынесена из `mcpserver`
    (−2,9 тыс. строк; с сервером инструментов её связывают три обратных
    вызова);
  - разбиты по смыслу файлы-монолиты: `jobs.go` (1787 строк),
    `workflow/engine.go`, `projectprofile/profile.go`,
    `rootbroker/rootbroker.go`, `ownerweb/connections.go` — перенос дословный,
    сверен построчно;
  - постоянная проверка `internal/archlint`: новый файл не длиннее 700 строк,
    оставшиеся длинные файлы и пакеты `mcpserver`/`rootbroker`/`executor`
    могут только уменьшаться.
- **Работа не встаёт на занятой H96:** подготовка запечатанного прогона идёт
  по гибкому бюджету (2 мин, под нагрузкой до 4), а если она всё же сорвалась,
  не запустив ничего, задача сама переподготавливается (до 3 попыток) под
  новой идентичностью — `project_test` не падает из-за нагрузки.
  Запечатанный прогон, который ещё нагружает CPU на своём бюджете, продлевается
  до общего потолка 6 ч, как обычные задачи (полный набор MCPshka ~34 мин
  обрывался на 1800 с); пробы контрактов тоже тянутся по нагрузке.
- **MCP-151 — честная статистика инструментов:** `tool_usage` хранит
  пожизненные счётчики (вызовы, ошибки, последний вызов) между перезапусками —
  `total_calls`, `never_called_since_ledger`; по ним видно мёртвые инструменты.
- **MCP-147 — «Узлы» на «Подключениях»:** добавить VPS (MCPshka создаёт свой
  ключ с `restrict`, показывает строку для `authorized_keys`), «Сверить ключ»
  хоста (новый / совпадает / сменился, старый и новый отпечаток), «Принять»
  только тот отпечаток, что владелец видел (подменённый в промежутке ключ не
  принимается), «Проверить связь» строгой проверкой ключа, «Удалить узел»
  (файлы откладываются в `.removed`). Вход на страницу — Face ID.
