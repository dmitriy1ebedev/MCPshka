# MCPshka 0.1.164 — агенты, вторая CI-площадка, ночной режим

## Агенты
- **`mcpshka_guide`** — справка для любого ИИ из самой MCPshka: правила работы (не останавливаться ради отчётов, вердикты брать у MCPshka, повтор с тем же `idempotency_key`), цикл фазы roadmap, восстановление, тесты, хост, площадки, индекс инструментов по категориям. Инструкции сервера отправляют каждого агента читать `topic=rules`.
- `project_test` поднимает слишком короткий лимит по прошлому успешному прогону; при таймауте набор останавливается сам и отдаёт частичный вывод (exit 124, `timed_out`).

## Площадки
- **Гейт интеграции принимает GitVerse CI** (`integration_test_prepare evidence=gitverse`): root пересчитывает детерминированный неизменяемый снимок коммита и принимает только прогоны `release-suite` + `snapshot-contracts` ровно на нём. В workflow снимков GitVerse добавлен `release-suite` (vet, полный тест, сборка ARM64).
- **`providers_status`** — площадки, квоты и правила владельца (платное запрещено везде; GigaIDE — только бесплатные ~60 ч/нед) с живой проверкой доступности; функция `providers.Allow` — единый шлюз для адаптеров.

## Ночной режим
- **`roadmap_next`** — следующий пункт roadmap любого проекта (Pxx у DIAG, `[ ]/[-]/[x]` у LANE).
- **`roadmap_run`** (окно Face ID) — MCPshka сама ведёт проект по roadmap: на каждую фазу свежая сессия Codex с правилами MCPshka, вердикт — `phase_gate`; одна повторная попытка с текстом блокера; остановка на настоящем блокере, лимите Codex, бюджете времени или числе фаз. **`roadmap_run_status`** — журнал и утренний отчёт.

## Прочее
- Профиль проекта: `runtime_paths`/`env` — ручной запасной путь для зависимостей вне коммита (корневой список `/etc/mcpshka/runtime-paths.allow`, дескрипторы только на чтение). Автоматическая сборка окружений проектов — 0.1.165.
