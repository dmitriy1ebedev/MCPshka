# MCPshka 0.1.165 — Codex ↔ Claude Code, причёсанные баги

## Агенты
- **Codex и Claude Code работают через MCPshka взаимно.** `agent_task` / `agent_task_status` (окно Face ID): любой агент поручает самодостаточную задачу другому — оба видят одни и те же инструменты MCPshka. Claude Code запускается в режиме `auto` (никогда bypass), Codex — как текущие операторские сессии.
- **Ночной прогон** (`roadmap_run`) использует обоих: при лимите одного переключается на другого, а если исчерпаны оба — ждёт ближайшего сброса (время берётся из сообщения агента) в пределах бюджета (BUG-33).

## Исправлено
- BUG-20261021-34: `canary-fence` отказывает, пока у запуска нет результата (это выбросило CI-доказательство при вливании 0.1.164); `canary-abort` — сознательное прерывание.
- BUG-20261021-27: `knowledge_search` работает с любым маленьким лимитом — индекс покрывает всю базу, а лимит ограничивает ответ; переполненный ответ усекается.
- BUG-20261021-32: проба GitVerse в `providers_status` с нужным Accept.
- BUG-20261020-20: lease закончившегося чата/агента на любом worktree — `project_lease_admin_stale_preview` / `..._stale_release` (Face ID, доказательство: нет heartbeat 2 ч, нет живого владельца и процессов в worktree; CAS-удаление ровно доказанной записи).
