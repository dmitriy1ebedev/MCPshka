# Версии MCPshka

Формат: `<этап>.<тир>.<релиз>`, например `0.1.55`.

- `0` — альфа.
- `1` во второй позиции — Tier 1 по roadmap.
- `55` — сквозной номер релиза; при смене тира он не сбрасывается.

Первый релиз нового формата — `0.1.55`, следующий после `0.1.a.54`.
Значения будущих этапов определяются отдельно при переходе из альфы.
Деплой сверяет полную строку версии с бинарником. Старые версии,
артефакты и материалы отката сохраняют исходные имена.
