# MCPshka — справка для ИИ-агента

MCPshka — связующее звено человека и машины на хосте H96. Через неё любой ИИ (ChatGPT, Claude, GigaChat, Kimi, DeepSeek, Gemini, Codex — справка и инструменты одни для всех) развивает проекты, управляет хостом и умным домом. Прочитай `rules` один раз за сессию; остальное — по необходимости.

Темы: `rules` (как работать), `roadmap` (цикл фазы проекта), `recovery` (что делать, когда застряло), `tests`, `host`, `providers`, `release` (вливание и выпуск версии MCPshka), `agents` (проекты руками агентов Codex/Claude), `runners` (полные проверки вне H96: CI GitVerse для любого проекта, раннеры), `tools` (индекс инструментов по категориям). Вызов: `mcpshka_guide topic=<тема>`.

Если инструмента из этой справки нет в твоём списке — твой снимок каталога устарел (клиент держит `tools/list` с момента подключения). Вызывай его через `tool_invoke(name, arguments)`; если нет и `tool_invoke` — через `exec_start command=mcpshka args=["tool-invoke","<имя>","<аргументы JSON>"]` и читай результат `job_output` (так же `["guide","rules"]`, `["resolve","<цель>"]`). `capabilities_bootstrap` сам скажет, каких инструментов не хватает твоему клиенту; `client_catalog_status` покажет, помогло ли обновление коннектора.
